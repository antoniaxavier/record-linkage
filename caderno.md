# aprendendo 
uv: alternativa ao pip mais rapido que permite gerenciamento de ambiente e complilação de dependencias 

`` uv python install 3.12 `` 
`` uv init --python 3.12  # inicia `` 
 `` uv venv  # Cria e ativa o ambiente ``
